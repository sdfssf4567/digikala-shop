# 🛒 فروشگاه اینترنتی دیجی‌شاپ (شبیه دیجی‌کالا)

یک فروشگاه اینترنتی کامل، فارسی و راست‌چین ساخته شده با **PHP 8 خالص** (بدون فریم‌ورک)، **MySQL**، **Bootstrap 5 RTL** و فونت **وزیرمتن**. این پروژه برای یادگیری و استفاده واقعی به‌صورت کامل و بدون خطا نوشته شده است.

---

## ✨ امکانات

### بخش کاربری (فروشگاه)
- صفحه اصلی با اسلایدر بنر، دسته‌بندی‌ها، پیشنهاد شگفت‌انگیز، جدیدترین‌ها و پرفروش‌ترین‌ها
- لیست محصولات با **فیلتر دسته‌بندی، برند، محدوده قیمت** و **مرتب‌سازی** (جدیدترین، محبوب‌ترین، ارزان‌ترین، بیشترین تخفیف) + صفحه‌بندی
- صفحه محصول با **گالری چند تصویری**، مشخصات فنی، محصولات مشابه و **نظرات با امتیاز ستاره‌ای**
- **سبد خرید کاملاً Ajax** (افزودن، تغییر تعداد، حذف بدون رفرش صفحه)
- **فرایند خرید چند مرحله‌ای** (سبد ← اطلاعات ارسال ← پرداخت) با روش پرداخت آنلاین یا در محل
- ثبت‌نام و ورود با اعتبارسنجی کامل
- پروفایل کاربری: ویرایش اطلاعات، تغییر رمز عبور، **تاریخچه سفارش‌ها** با وضعیت هر سفارش
- **جستجوی زنده (Live Search)** با نتایج آنی در هدر
- **لیست علاقه‌مندی‌ها** (قلب) با یک کلیک
- قیمت‌ها با جداکننده هزارگان و **اعداد فارسی** + تاریخ شمسی

### پنل مدیریت (`/admin`)
- **داشبورد** با آمار کلی (فروش، سفارش‌ها، کاربران، محصولات) و **نمودار فروش ۱۴ روز اخیر** (Chart.js)
- **مدیریت محصولات**: افزودن/ویرایش/حذف + **آپلود چند تصویر** برای هر محصول + مشخصات فنی + تخفیف + موجودی
- مدیریت دسته‌بندی‌ها (با ساختار والد/فرزند)
- **مدیریت سفارش‌ها**: مشاهده جزئیات + تغییر وضعیت (در انتظار ← ارسال شده ← تحویل داده شده / لغو)
- مدیریت کاربران
- **مدیریت نظرات**: تایید / رد / حذف
- **مدیریت بنرها و اسلایدر** با آپلود تصویر
- **گزارش فروش**: پرفروش‌ترین محصولات، فروش به تفکیک دسته‌بندی و وضعیت

### امنیت
- `password_hash` و `password_verify` برای رمزهای عبور
- **PDO + Prepared Statement** در تمام کوئری‌ها (ضد SQL Injection)
- **توکن CSRF** در تمام فرم‌ها و درخواست‌های Ajax
- `htmlspecialchars` در تمام خروجی‌ها (ضد XSS)
- اعتبارسنجی کامل سمت سرور + بررسی نوع واقعی فایل در آپلودها
- کوکی نشست `httponly` + `session_regenerate_id` هنگام ورود

## 🚀 نصب و راه‌اندازی (XAMPP)

### ۱) نصب XAMPP
ابتدا [XAMPP](https://www.apachefriends.org/) را دانلود و نصب کنید (نسخه با PHP 8 یا بالاتر).

### ۲) کپی پروژه
پوشه `digikala-shop` را داخل پوشه `htdocs` کپی کنید:

```
C:\xampp\htdocs\digikala-shop      (ویندوز)
/opt/lampp/htdocs/digikala-shop    (لینوکس)
```

### ۳) اجرای Apache و MySQL
در پنل XAMPP، دو ماژول **Apache** و **MySQL** را Start کنید.

### ۴) ساخت دیتابیس و ایمپورت SQL
1. در مرورگر آدرس `http://localhost/phpmyadmin` را باز کنید.
2. از منوی سمت راست روی **New** کلیک کرده و دیتابیس جدیدی با نام `digikala_shop` و Collation از نوع `utf8mb4_unicode_ci` بسازید.
   > (اگر فایل `database.sql` را بدون تغییر اجرا کنید، این مرحله خودکار انجام می‌شود)
3. روی دیتابیس ساخته‌شده کلیک کرده و از تب **Import**، فایل `database.sql` را انتخاب و **Go** بزنید.
4. صبر کنید تا ایمپورت کامل شود (۱۲ جدول + داده‌های نمونه ساخته می‌شود).

### ۵) تنظیم اتصال (در صورت نیاز)
اگر نام کاربری/رمز دیتابیس شما متفاوت است، فایل `config/config.php` را ویرایش کنید:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'digikala_shop');
define('DB_USER', 'root');
define('DB_PASS', '');
```

> آدرس پایه سایت **خودکار** تشخیص داده می‌شود؛ نیازی به ویرایش نیست.

### ۶) باز کردن سایت
- **فروشگاه:** `http://localhost/digikala-shop`
- **پنل مدیریت:** `http://localhost/digikala-shop/admin`

## 📝 نکات مهم

- برای آپلود تصویر محصول/بنر، پوشه‌های `assets/images/products` و `assets/images/banners` باید **قابل نوشتن** باشند (روی لینوکس: `chmod -R 775 assets/images`).
- نظرات کاربران پیش از نمایش، باید در پنل مدیریت **تایید** شوند.
- داده‌های نمونه شامل ۲۴ محصول، ۸ دسته‌بندی، ۱۵ برند، ۴ سفارش و ۱۱ نظر است تا داشبورد و گزارش‌ها از ابتدا پر باشند.
- تصاویر نمونه پروژه به‌صورت SVG تولید شده‌اند؛ در پنل مدیریت می‌توانید تصاویر واقعی (JPG/PNG/WebP تا ۵ مگابایت) آپلود کنید.
- درگاه پرداخت به‌صورت **نمایشی** پیاده‌سازی شده است؛ برای اتصال به درگاه واقعی (زرین‌پال و...) متد پرداخت را در `CheckoutController` توسعه دهید.
